# CyberAware BIS305 Starter

Features: registration/login, six training topics, quiz, phishing scenarios, awareness score, recommendations, progress tracking, admin dashboard, charts, mobile-friendly UI.

## Run
1. `python -m venv venv`
2. Windows: `venv\Scripts\activate`
3. `pip install -r requirements.txt`
4. `python app.py`
5. Open `http://127.0.0.1:5000`

Demo admin: `admin@cyberaware.local` / `Admin123!`

Change the demo password and SECRET_KEY before any real deployment.
