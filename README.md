# Project-3-CyberAware-Mobile-Cybersecurity-Awareness-Risk-Assessment-System
Ashish 240010, Saurav 240312, Abhinav 240313, Muhammad Abu Bakar 240179

Client: SmallBiz Connect
Client Background
SmallBiz Connect is concerned that its employees have limited awareness of common
cybersecurity threats. Management wants to improve cybersecurity awareness without
purchasing an expensive commercial training platform.
The organisation has approached your development team to build a mobile
cybersecurity awareness and self-assessment application.
Client Requirements
The proposed application must:
1. Allow users to create an account and securely log in.
2. Provide cybersecurity awareness activities covering topics such as:
o Phishing
o Password security
o Social engineering
o Malware
o Safe browsingo Multi-factor authentication
3. Provide interactive quizzes or scenario-based questions.
4. Allow users to assess whether an example email or message is potentially
malicious.
5. Calculate a Cybersecurity Awareness Score based on user performance.
6. Provide personalised feedback based on quiz results.
7. Track user progress over time.
8. Provide a management dashboard showing aggregated information such as:
o Average awareness score
o Quiz performance
o Most frequently incorrect questions
o Training completion
o Overall risk levels
9. Provide visual analytics showing changes in awareness scores over time.
10. Generate recommendations based on areas where users perform poorly.
